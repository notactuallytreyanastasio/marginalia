# pages_works

The drafts page and the upload page: `WorkLive.Index` (the folder tree with
drag and drop, rename, delete, the backfill), `WorkLive.New` (the form, the
fetch of a web page) and `WorkController.create` (`POST /works/new`) of the
Phoenix app. The page for one draft, `/works/:id`, is another group.
